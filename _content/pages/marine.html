Sensor Drivers & Interfaces

I develop and maintain ROS 2 drivers for cameras, GNSS receivers and an IMU. My work includes sensor configuration, message interfaces, lifecycle transitions and recovery when a device stops providing data.

Software Architecture & Navigation

I define the structure and interfaces of the navigation software for the LM450 uncrewed surface vessel (USV), connecting state estimation, planning, mission execution, vehicle modes and control. I work on component composition and data flow, and investigate behaviour across driver and application boundaries.

Embedded Integration & Perception

I adapt the Linux environment for the computing platform, integrate sensor drivers and deploy perception software on NVIDIA Jetson. This includes a semantic segmentation pipeline, with model fine-tuning and on-device inference.

The embedded controller combines computing, positioning, communications and I/O for outdoor robotics. My work on its software supports the platform’s use beyond an individual vessel application.

Testing & Software Delivery

I test software in simulation and during field deployments, using logs, telemetry and visualisation to investigate faults. I develop automated build and test workflows, code coverage checks and Debian packaging for repeatable delivery.
